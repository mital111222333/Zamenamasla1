# Система учёта замены масла

Telegram-бот + сайт (веб-панель) для пункта автозамены масла: подробная база
клиентов и машин, полная история обслуживания за все годы, автоматические
повторные напоминания клиентам через Telegram, быстрая отправка ссылки в
WhatsApp, информация о пункте прямо в боте.

## Как это работает

**Хозяин пункта (админ)** пользуется сайтом или ботом:

- **Сайт** — вкладка «Внести замену» (форма: госномер, владелец, телефон,
  авто, пробег, тип услуги, масло, менялся ли фильтр, стоимость, через
  сколько месяцев напомнить, заметки) и вкладка «База» (таблица всех машин
  с поиском; кнопка «подробнее» разворачивает полную историю по машине).
  Для нового клиента сразу после сохранения выскакивает окно с QR-кодом,
  ссылкой и кнопкой **«Отправить в WhatsApp»** — один клик, и клиенту уходит
  готовое сообщение со ссылкой.
- **Бот**: `/add` — та же форма пошагово в чате (тоже с кнопкой WhatsApp в
  конце); `/find` — поиск по госномеру с полной историей.

**Автовладелец (клиент):**
- Переходит по ссылке/QR или из WhatsApp-сообщения → `/start` → сразу
  привязан, без единого лишнего вопроса.
- В меню бота: **«🕒 Моя история»** — вся история обслуживания по каждой
  своей машине (дата, тип услуги, масло, менялся ли фильтр, пробег,
  стоимость, следующая замена, заметки); **«ℹ️ О пункте»** — название,
  адрес, телефон, часы работы и геолокация пункта.
- Напоминания: первое — когда подошёл срок, дальше — **раз в 2 недели**,
  максимум 6 раз, пока клиент не нажмёт «Уже поменял» или «Записаться».
  При записи админу сразу приходит уведомление с номером авто и телефоном.

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите
   `BOT_TOKEN` и **username бота** (без `@`).
2. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot) —
   это `ADMIN_TELEGRAM_ID`.
3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Задайте переменные окружения:
   ```
   export BOT_TOKEN="ваш_токен_от_botfather"
   export ADMIN_TELEGRAM_ID="ваш_telegram_id"
   export BOT_USERNAME="username_бота_без_собаки"

   # необязательно, но рекомендуется — показываются клиенту по кнопке "О пункте"
   export SHOP_NAME="MITAL — пункт замены масла"
   export SHOP_PHONE="+998901112233"
   export SHOP_ADDRESS="Андижан, ул. Богишамол 12"
   export SHOP_HOURS="Ежедневно 9:00–19:00"
   export SHOP_LAT="40.7821"
   export SHOP_LON="72.3442"
   ```
5. Запустите:
   ```
   python bot.py
   ```
   Бот (polling) и сайт (на порту из `PORT`, по умолчанию 8000) работают в
   одном процессе.

## Бесплатный хостинг (Railway)

1. Залейте все файлы в GitHub-репозиторий.
2. На railway.app создайте проект из этого репозитория.
3. Во вкладке Variables задайте все переменные из шага 4 выше.
4. Во вкладке Settings → Networking нажмите «Generate Domain» — это адрес
   сайта.
5. `Procfile` (`web: python bot.py`) подхватится автоматически.

⚠️ **Если у вас уже был развёрнут более ранний вариант бота** — просто
замените файлы новыми и передеплойте. При первом запуске `database.py`
сам добавит недостающие колонки в существующую базу (`ALTER TABLE`),
ничего из старых данных не удаляется.

## База данных

SQLite (`oil_bot.db`), создаётся и обновляется автоматически. Таблицы:
- `clients` — телефон, имя, персональный `link_token`, `telegram_id` после
  привязки.
- `cars` — госномер (уникален), привязка к клиенту, марка/модель.
- `oil_changes` — подробная история обслуживания: дата, пробег, тип услуги,
  марка масла, менялся ли фильтр, стоимость, интервал в месяцах, дата
  следующей замены, заметки, счётчик и дата последнего напоминания, статус
  (`active` / `booked` / `changed_elsewhere` / `done`).

⚠️ SQLite-файл живёт на диске контейнера — на бесплатных тарифах хостингов
диск может быть непостоянным между деплоями. Стоит либо включить постоянный
volume, либо периодически делать бэкап файла `oil_bot.db`.

## Возможные доработки на будущее

- Экспорт истории и списка клиентов в Excel/CSV прямо с сайта — удобно для
  бэкапа и отчётности.
- Разделение на несколько пунктов замены (если появится вторая точка).
- Простая статистика на сайте: сколько клиентов за месяц, сколько записей
  ожидает напоминания на этой неделе, суммарная выручка по `cost`.
- SMS как резервный канал для тех, кто не пользуется Telegram/WhatsApp.
- Печатные QR-стикеры на выдачу вместе с чеком.
