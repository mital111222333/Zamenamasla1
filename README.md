# Система учёта замены масла

Telegram-бот + сайт (веб-панель) для пункта автозамены масла: база клиентов
и машин, полная история замен за все годы, автоматические напоминания
клиентам через Telegram раз в N месяцев.

## Как это работает

**Хозяин пункта (админ)** пользуется либо сайтом, либо ботом — что удобнее
в моменте:

- **Сайт** — открывается в браузере (с телефона или компьютера) по обычной
  ссылке. Вкладка «Внести замену» — форма; вкладка «База» — таблица всех
  машин с поиском. Для клиента, который ещё не привязан к боту, в таблице
  есть кнопка «показать ссылку» — там появится персональная ссылка и QR-код.
- **Бот**: `/add` — та же форма, но пошагово в чате; `/find` — поиск по
  госномеру с полной историей и статусом привязки клиента.

**Автовладелец (клиент):**
- Получает от вас персональную ссылку или QR-код (генерируются при добавлении
  новой машины — на сайте или в боте).
- Переходит по ссылке → нажимает Start в Телеграме → сразу привязан,
  без ввода телефона.
- Когда подходит время замены (по умолчанию через 3 месяца после последней
  записи — интервал задаётся при каждой замене), приходит напоминание с
  кнопками «Уже поменял» / «Записаться».

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите
   `BOT_TOKEN` и **username бота** (например `oil_reminder_bot`, без `@`).
2. Узнайте свой Telegram ID (например, через [@userinfobot](https://t.me/userinfobot)) —
   это `ADMIN_TELEGRAM_ID`, чтобы бот отличал вас от обычных клиентов.
3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Задайте переменные окружения:
   ```
   export BOT_TOKEN="ваш_токен_от_botfather"
   export ADMIN_TELEGRAM_ID="ваш_telegram_id"
   export BOT_USERNAME="username_бота_без_собаки"
   ```
5. Запустите:
   ```
   python bot.py
   ```
   Это одновременно запускает бота (polling) и сайт на порту из переменной
   `PORT` (по умолчанию 8000) — они работают в одном процессе.

## Бесплатный хостинг (чтобы работало круглосуточно)

Проще всего через **Railway**:
1. Зайдите на railway.app, создайте новый проект из GitHub-репозитория с этим
   кодом (или загрузите файлы напрямую).
2. В настройках проекта добавьте переменные окружения `BOT_TOKEN`,
   `ADMIN_TELEGRAM_ID`, `BOT_USERNAME` (и, по желанию, `PUBLIC_URL` — публичный
   адрес, который Railway выдаст сайту, для подсказки в `/start`).
3. Railway автоматически подхватит `Procfile` (`web: python bot.py`) и
   привяжет публичный домен к порту, на котором слушает сайт — по этому
   домену вы и будете открывать веб-панель.
4. Бесплатного тарифа Railway достаточно для одного такого бота с небольшой
   нагрузкой.

## База данных

Используется SQLite (`oil_bot.db`), создаётся автоматически при первом
запуске. Три таблицы:
- `clients` — автовладельцы: телефон, имя, персональный `link_token` для
  ссылки/QR, `telegram_id` после привязки
- `cars` — машины (госномер уникален, привязка к клиенту — у одного клиента
  может быть несколько машин под одной ссылкой)
- `oil_changes` — история замен, каждая запись отдельной строкой, ничего не
  перезаписывается; интервал до следующей замены задаётся в месяцах

⚠️ SQLite-файл живёт на диске контейнера — на бесплатных тарифах хостингов
диск может быть непостоянным между деплоями. Если база важна на годы вперёд,
стоит либо включить постоянный volume (если хостинг поддерживает), либо
периодически делать бэкап файла `oil_bot.db`.

## Возможные доработки на будущее

- Разделение на несколько пунктов замены (если появится вторая точка).
- Экспорт истории в Google Таблицу для отчётности.
- SMS-напоминания как резервный канал для тех, кто не пользуется Telegram.
- Печатные QR-стикеры на выдачу вместе с чеком (сейчас QR только на экране).
